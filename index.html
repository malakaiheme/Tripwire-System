Introduction

Homeowners often get little warning when someone enters their property. By the time they notice, they have already lost valuable time to react.

This project is a laser tripwire system that watches areas around the home, such as doors, windows, and the yard. When a person breaks the beam, the system detects the change and immediately alerts the occupants with the location of the intrusion. This gives people earlier and more accurate awareness of a threat so they can call for help and make safe decisions.

We'll measure succes by ensuring that the system has a detection rate of at least 90%, by making sure the response time is quick, and by making sure the laser is still and does not move when the system is activated. The system will be tested in a controlled environment to ensure that it meets these criteria.

Some of the problems we will face will include; budget, time, parts, and personal skills. Through out of these problems the budgetting will the most troublesome as it will require us to bring in our own materials such as a camera. The other problems aren't as hard to deal with as; we can split the workload amonst ourselves to save time, majority of the parts are already given to us, and if we are lacking skills to code the script of the tracker then we can use A.I. to give us examples and explain the work that needs to be done/fixed.

Environmental Impact Assessment

    Environmental Impact Assessment

    • Materials: The trip wire system uses an Arduino Uno, infrared sensors, wires, and other electronic components. Reusable and recyclable materials help reduce electronic waste.
    • Energy Efficiency: The system uses low-power infrared sensors and an Arduino, which consume minimal electricity.
    • Reusability: Sensors, wires, and the Arduino can be reused in other projects, reducing electronic waste.
    • Packaging & Shipping: Ordering components from one supplier can reduce packaging materials and transportation emissions.
    • Sustainability: Using rechargeable batteries and energy-efficient components helps reduce the project's environmental footprint.

    Comparative Analysis of Technologies – Trip Wire System

    Technology Advantages Disadvantages Sustainability
    Infrared (IR) Sensor Affordable, easy to install, and detects objects without physical contact. Can be affected by sunlight and environmental conditions. Uses little electricity and can be reused.
    Laser and LDR Sensor Detects when an object interrupts a beam and provides a clear detection point. Requires careful alignment and can be affected by bright light. Uses relatively little power and has inexpensive replacement parts.

    Final Decision

    I would choose the infrared sensor system because it is affordable, easy to install, and does not require a visible laser beam. It is reusable and uses little electricity, making it a good option for my trip wire project.

Arduino Code

The following Arduino code controls the system, lighting LEDs and activating the buzzer based on distance readings from the HC-SR04 sensor.

 
  
// Tracking Laser System  (HC-SR04)
// Author: Ana Rodrigues
// Oct 2, 2025
// Object is farther than 50cm: Green LED lights up
// Object is closer than 50 cm, but more than 10cm away: Yellow LED lights, buzzer plays 300Hz tone
// Object is closer than 10cm: Red LED lights up, buzzer plays 500Hz tone

//LED pins
const int greenLED = 2;
const int yellowLED = 3;
const int redLED = 4;

// Ultrasonic sensor pins
const int trigPin = 9;
const int echoPin = 10;

// Passive buzzer pin
const int buzzer = 11;

void setup() {
  pinMode(greenLED, OUTPUT);
  pinMode(yellowLED, OUTPUT);
  pinMode(redLED, OUTPUT);
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  Serial.begin(9600);
}

void loop() {
  // Measure distance
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  long duration = pulseIn(echoPin, HIGH);
  long distance = duration * 0.034 / 2;

  Serial.print("Distance: ");
  Serial.print(distance);
  Serial.println(" cm");
  
  //Error in measurement:
  if (distance <= 0)
    return;

  //Too close:
  if (distance <= 10) {
    digitalWrite(greenLED, LOW);
    digitalWrite(yellowLED, LOW);
    digitalWrite(redLED, HIGH);
    tone(buzzer, 500); // Play 500Hz tone
    return;
  }

  //Midrange:
  if (distance <= 30) {
    digitalWrite(greenLED, LOW);
    digitalWrite(yellowLED, HIGH);
    digitalWrite(redLED, LOW);
    tone(buzzer, 300); // Play 300Hz tone
    return;
  }

  //Normal status:
  digitalWrite(greenLED, HIGH);
  digitalWrite(yellowLED, LOW);
  digitalWrite(redLED, LOW);
  noTone(buzzer); // stop buzzer

  delay(100);
}

Conclusion

The system effectively demonstrates distance-based alerting using Arduino. It’s affordable, educational, and sustainable through reusable components.
